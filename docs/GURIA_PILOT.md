# Guria Agricultural Pilot Deployment Plan

## 1. Pilot Scope
- **Region:** Guria (Ozurgeti / Chokhatauri / Lanchkhuti districts).
- **Primary Crops:** Hazelnuts (თხილი), Blueberries (მოცვი), Tea plantations.
- **Participating Farms:** Pilot cooperatives and commercial plantations.

## 2. Key Objectives
1. **Offline Field Weighing:** Test barcode/QR scanning of collection boxes at field collection points.
2. **Picker Productivity & GPS Tracking:** Monitor picker consistency and payroll calculations using smart GPS cards and daily net weight cards.
3. **Soil & Microclimate Telemetry:** Deploy local soil probe data and regional microclimate analysis via Gemini 2.5.
4. **Local LAN Continuity:** Validate uninterrupted operations using the local plantation server node during cellular blackouts.
